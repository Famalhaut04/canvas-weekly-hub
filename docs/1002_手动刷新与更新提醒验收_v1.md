## 交互与保存规则

| 入口 / 情况 | 实际行为 | 验证 |
|---|---|---|
| 顶栏“刷新课程”与提醒内同名按钮 | 共用原 `fetchAll`、任务互斥与 `boot`，使用已保存配置；不是重载缓存 | Node + Edge |
| 刷新过程中 | 显示“刷新中…”，禁用重复入口；结束恢复，旧看板可阅读 | Node + 两个真实标签页 |
| 满 N 天 | N×24 小时，默认 3 天 / 72 小时；显示温和提示，**没有自动 Canvas 请求** | 小于 / 等于 / 大于 72 小时夹具 + Edge 边界 |
| “暂不刷新” | 只隐藏本页面本次提示，不改成功时间或数据；重开可重新提醒 | Node + 原生 Enter 键 |
| “保存提醒设置” | 仅存开关与至少 1 天的整数天数，不保存 Token 草稿 | Node + Edge 手机 |
| 关闭提醒 | 隐藏提醒，手动按钮仍可用；重载保留设置 | Node + 第二个真实标签页 |
| 打开、恢复可见、聚焦、pageshow | 重新比较本地时间；可见页面最多每分钟校对，并在阈值附近安排检查 | Node 可控时钟 + Edge 事件 |
| 后台、休眠、关闭页面 | 后台暂停本项目提醒定时检查，恢复后比较；关闭后不保证提醒，不抓取 | Node 时间跳跃；未做真实长时间休眠实验 |
| 成功读取并保存 | 关键课程 / 作业读取完成后记录 epoch 毫秒，与看板 / 快照一起保存；按设备时区显示 | Node + Edge |
| 课件 / 公告部分失败 | 保存可用结果与成功时间，明确显示缺失内容警告 | Node 可选请求 403 夹具 |
| 401 / 403 / 502 / 503、超时、网络中断 | 保留旧配置、看板、快照和成功时间；401 提醒换 Token，403 提醒核对权限 / 访问限制，5xx 提醒检查个人助手部署 / 学校接口 / 网络，不能据此认定过期 | Node 夹具 |
| 写入失败 | 不宣称成功，尽力回滚整组旧值；不会无限重试或弹窗打断阅读 | Node 单次写入故障夹具 |
| 更换学校 / Worker / Token | 当前配置摘要绑定提醒；仅检查连接成功时新绑定时间为空，抓取保存成功后重新记录 | Node |
| 查询期间另页改配置 | 提交前再次校对当前绑定，变化则拒绝保存这次结果 | Node |
| 历史导入 | 替换看板 / 快照，更新时间设为未知；导入不是一次学校查询 | Node + 原有备份验证 |
| 清除本机数据 | 清除提醒设置和成功时间，默认恢复 3 天；不撤销学校 Token | Node |
| 多标签页 | 同源 Web Locks 使用 `ifAvailable`，竞争者提示等待，不排队补抓；不广播 Token / 正文 | Node + 两个真实 Edge 标签页 |
| 不支持 Web Locks | 明确提示使用现代浏览器 / 个人 HTTPS 网址，保留旧看板；不使用不可靠的存储抢锁回退 | Node 能力缺失夹具 |
| 升级版本地看板 | 按钮沿用本机 POST `/refresh`，Python 直接查询学校；没有新增三天自动任务 | 模板核对 + 本地接口回归 |
| 导出离线 HTML | 仍是静态快照，无网页设置与凭证；不主动查询学校 | Edge 导出 + 源码核对 |

`hubUpdateReminder` 仅保存 `{enabled, days}`。`hubRefreshState` 保存状态版本、当前 Worker / 学校 / Token 的 SHA-256 绑定摘要与成功毫秒时间；摘要不向网络发送，也不复制明文 Token。Token 原有存储方式未改变。浏览器存储不是加密保险箱。

旧时间兼容读取仅接受有效的 `YYYY-MM-DD HH:mm` 和明确的 `UTC±偏移`，同时要求旧看板学校与当前已保存配置匹配；例如 `2026-10-01 12:30 / UTC+8` 对应 `2026-10-01T04:30:00Z`。缺少偏移、日期非法、状态损坏或绑定不匹配时显示“更新时间未知，可手动刷新”。兼容读取不覆盖历史，也不把页面打开算成成功刷新。旧数据本身没有可靠账号标识，不能从同校地址证明历史属于当前账号；切换账号前建议备份并清除旧历史。

一次页面暂不刷新按当前绑定、成功时间和天数记录。显式改提醒天数或成功完成新刷新后重新判断；它不跨页面持久保存。当前历史周选择不会改变成功时间，提醒也不保证某张历史快照已变成最新。

浏览器多个键的保存不是原子事务：代码使用原来的“写入失败尽力恢复”机制。如果浏览器同时拒绝回滚写入，无法保证所有旧值完整恢复，不作超出实现的承诺。

## 隐私边界与尚未验证

查询仍由用户点击发起，经自己的浏览器 → 自己的 Worker → 学校；不经过作者服务器，不上传作者仓库。不新增 KV、Cron、SendKey、通知权限或云端凭证存储，`github.push_enabled` 仍为 false。提醒与成功记录只在当前浏览器；课程备份没有匿名化。GitHub 星数仍使用独立公开请求，不携带 Canvas 凭证或课程数据。本地 Python 直接查询学校；云端 agent 读取配置 / 课程会引入模型服务商的数据边界。

| 尚未验证 / 剩余问题 | 边界与建议 |
|---|---|
| 真实个人 Worker 与学校 Canvas | 无真实账号实测；须由用户自行部署新代码并验证，不能把本地 Worker 夹具当正式部署 |
| Safari / iOS、真实手机、长时间休眠 / 后台冻结 | 已做 Edge 手机视口与可控时间测试，未在这些设备和长时场景实测；后台不作准点承诺 |
| 系统时间手动回拨 | 采用设备 epoch 比较，回拨可能延迟提醒；请使用正确系统时间，不把该提醒当作可靠闹钟 |
| 历史与快照未按账号分目录 | 本轮只绑定提醒时间；旧历史仍可能与新账号混用，换账号先备份 / 清除，后续独立迁移修复 |
| 作业范围、缺 URL 同名去重 | 具体证据见上表；未替用户更改产品范围，Issue #4 实际根因仍待验证 |
| 既有本地风险 | Python 离线 JSON 转义、本地产物非原子保存、loopback `/refresh` 无 Origin 检查、地址校验前后差异等沿用前次核对报告；本轮没有擅改架构 |
| 发布与旧附件 | 本轮未发布。线上入口和 v2.2 附件仍是以前版本，不含新提醒；本地文档已区分状态，个人实例不会自动升级 |

跨标签协调依据 [MDN Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API)：同源锁协调独占任务，`ifAvailable` 无锁时立即返回，HTTPS / 安全上下文使用。本轮以两个真实 Edge 标签页验证实现，并给出能力缺失的明确错误，不声称所有旧浏览器可用。
