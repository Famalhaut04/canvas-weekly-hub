## 内容校验

对网页、概述、部署包以 UTF-8 编码并统一 LF 换行后比较 SHA-256，三个文件均与本地一致：

```text
web/index.html  0199ef085917dd8a4378d918fced43f6ec1d522d6b575c22f1cbc1f1c7f00ef3
web/overview.html  ab6ff98439976c91ff969f9112d5f23b2e5cf8075c46e69bd53ac3c26ff969bd
worker.js  18717bfb60341eda8fccf83b6af372a528f382f111512a6ac344da817ce647d9
```

Release 中上传的 worker.js 保留 Windows 换行，大小 122301 字节，GitHub 返回原始摘要 sha256:9ffc39281440b1d014ab9f959b45483c30a1f3379583f0379a743824c4eec81d。统一换行后的源码一致，原始字节摘要不同不是代码差异。

本机 Python 3.8 的 Windows 证书存储读取异常，在线核验改用 PowerShell 的正常 HTTPS 验证完成，没有关闭证书校验。

## 使用边界

发布的是通用代码、公共静态引导页和公告，不包含个人令牌、课程数据或真实账号截图。每位用户的 Worker 仍需自己部署或更新；没有替任何个人 Cloudflare 实例部署，也未用真实 Canvas 账号做端到端验证。

云端订阅 / 微信入口暂停，KV 与 Cron 不默认配置。已升级 Worker 的旧 Cron 为空操作；旧 KV 不自动清空，用户按教程自行停用与撤销旧凭证。GitHub 星数请求保留，不携带 Canvas 信息。

完整验证见 [一体化升级验收](1002_v2.2一体化升级验收_v1.md)。
