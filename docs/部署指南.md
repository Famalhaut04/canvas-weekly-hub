# 本地部署指南 · Python / agent · v2.2

本地引擎直接查询学校 Canvas，不经过 Worker 或作者服务器，生成周报、看板、日历和课件文件。普通同学无需配置 Python，可以用 [网页部署教程](Cloudflare部署图文教程.md)。系统各部分见 [系统概述](系统概述.md)。

下载 [v2.2 更新源码附件](https://github.com/Famalhaut04/canvas-weekly-hub/releases/download/v2.2/canvas-weekly-hub-v2.2-source.zip) 并解压，或克隆 main。GitHub Release 自带的 Source code (zip / tar.gz) 来自保留的历史标签，不包含本次同版本修改；不要混用旧代码与新教程。

## 最短配置流程

需要已有 Python 3.8+，仅用标准库。下载或克隆项目，然后在项目目录操作：

1. 复制 `config/canvas_config.example.json` 为 `canvas_config.json`。
2. 先确认学校允许个人 API 使用。城大从 https://canvas.cityu.edu.hk/ 登录，在“账户 → 设置 → 新访问令牌”填写用途及学校要求的到期日，按只显示一次处理，生成后立即复制；其他学校用自己的入口。生成按钮不可用时联系学校。官方资料对能否重看描述不同，以学校界面为准；丢失时按该校再生 / 创建功能更换。
3. 自己在本地编辑 JSON 的 `canvas_url` 和 `access_token`，不把真实 Token 发进聊天；保持 github.push_enabled=false。token_expires_at 是选填提醒，不影响学校令牌的实际期限，学校生成页可能必填。
4. 检查配置并运行：

```bash
python canvas_weekly_report.py --check-config
python canvas_weekly_report.py
python serve_board.py
```

三条命令在项目目录用同一个已有 Python 3.8+ 解释器执行；若 python 不在 PATH，使用自己解释器的完整路径，不能直接照搬他人机器的路径。PowerShell 可先执行 `Copy-Item -LiteralPath config/canvas_config.example.json -Destination canvas_config.json`，已有配置时先保留副本，避免覆盖。

`--check-config` 不访问网络，不生成周报，输出 CONFIG_OK 只证明格式通过，不证明 Token 或课程权限。通过后再抓取，以实际成功输出为准。引擎运行后可双击“我的学习网站.html”离线快照，或打开本地服务的 `http://localhost:8137/`。本地服务只监听 loopback，刷新按钮调用本机引擎，不公开配置和下载目录。离线 HTML 不会自己更新；本地定时运行可重新生成文件，打开时需重载。

本路线不需要 Cloudflare、KV 或云端定时器。网页配置窗口选择“升级版”即可查看本地 Python / agent 步骤和复制按钮；“基础版”提供网页部署路线。复制失败可在展开的文本框手动复制。同一份 [agent 配置提示词](1002_agent本地配置提示词_v1.md) 要求先读实现、用户自行填 Token、先检查再抓取，不安装依赖或自动上传。

本项目不是学校批准的 OAuth 应用。[Canvas 官方要求面向其他用户的应用使用 OAuth](https://developerdocs.instructure.com/services/canvas/oauth2/file.oauth)；个人本地使用是否获准需向学校确认，不因采用本地路线而自动豁免。

## 配置字段

| 字段 | 用途 / 默认 |
|---|---|
| `canvas_url` | 学校 HTTPS 站点，不带路径、账号或参数 |
| `access_token` | 自己生成的令牌，不能为空或带空白 |
| `token_expires_at` | 选填 YYYY-MM-DD 到期日 |
| `token_remind_days` | 提前提示天数，默认 5 |
| `lookback_days` / `upcoming_days` | 新内容回溯 / 截止覆盖天数，默认 7 |
| `tz_offset_hours` | 展示时区，默认 8 |
| `download_files` / `download_dir` | 是否下载新课件及目录 |
| `term_filter` | 学期名关键字，空值表示全部活跃课程 |
| `github.repo_dir` | 自己已有 Git 仓库目录；仅本地时留空 |
| `github.push_enabled` | 默认 false；显式开启才自动提交、推送结果 |

配置支持 UTF-8 BOM。源码运行默认数据目录是 canvas_weekly_report.py 所在目录（不是任意当前工作目录），配置为该目录的 canvas_config.json；指定 CANVAS_HUB_DATA_DIR 时配置与产物改用该目录，打包版默认在可执行文件旁。serve_board.py 使用同一数据目录。运行输出会列出产物位置，配置检查不修改原文件。

## 每次运行会做什么

| 部分 | 结果 |
|---|---|
| 查询 | 活跃课程、作业、提交状态、文件清单和公告 |
| 分析 | 近期内容、即将截止任务、改期、新评分与移除 |
| 周报 | 本地 Markdown，便于自己或 agent 阅读 |
| 看板 | data.json、离线 HTML、日历 ICS |
| 下载 | 开启后下载近期课件到本地 |
| GitHub 备份 | 默认关闭；开启后上传到你配置的仓库 |

作业查询失败中止本次更新，不保存错误快照；课件、公告读取部分失败会标记警告。所有课程数量与内容以实际运行输出为准。

## agent 或计划任务自动运行

在自己已有的 agent 或系统计划任务中，按需要定时运行：

```text
运行自己项目目录的 canvas_weekly_report.py。
成功后读取本次生成的周报，汇报真实课程动态和近期截止任务。
失败时如实报告错误，不编造课程、作业、数量。
不需要云端备份时保持 github.push_enabled=false。
```

电脑、运行环境和网络必须在线。若使用云端 agent，输入的凭证或被其读取的课程内容可能发送给模型服务商；让用户自己填 Token 并运行，提供脱敏报错优先，不能宣称全程只在本机。不要在聊天、日志、截图或 Git 提交中输出 Token。项目不要求使用 agent；系统计划任务也能运行。网页版云端订阅和微信入口暂停，不影响本地计划任务。

## 可选：自己的私有仓库备份

需要已有 Git、自己的仓库与认证。先检查仓库是自己的且为私有，再设置对应 repo_dir、用户名与仓库名，明确开启 push_enabled。运行会将看板相关文件复制到该仓库并自动 commit / push。

**不要把课程数据公开到 GitHub Pages。** 私有仓库备份与私有网页不是同一件事；本项目推荐在本机查看个人课程看板。公共项目入口只托管通用代码，不应上传个人 data.json、周报或课件。

## 维护与排错

| 情况 | 处理 |
|---|---|
| 配置检查失败 | 按字段提示修正 JSON、学校地址、日期或仓库路径 |
| 401 | 在 Canvas 更换令牌 |
| 403 / 网络失败 | 确认账号权限及学校网络可达 |
| 推送失败 | 本地周报仍可能已生成，检查仓库认证与权限 |
| 看板没更新 | 检查本次运行结果位置，本地服务读取的是引擎本地数据 |
| 令牌泄露 | 在 Canvas 立即撤销并生成新的令牌 |

令牌不是只读密码，必须保密。配置和个人产物已列入 .gitignore，但不要因此忽略提交前检查；已跟踪文件不会被忽略规则自动移除。所有导出文件都可能包含课程隐私。
