# Canvas Weekly Hub 配置与体验升级方案

日期：2026-10-02。依据：当前仓库源码，基线提交 `7c7dd64`。本文是升级方案，不代表已经发布或完成实测。

用户已选择 A 路线。实施结果和实际验证输出见 [升级验收报告](1002_配置体验升级验收_v1.md)。B、C 保留为后续可选路线。

## 当前问题

| 问题 | 源码位置 | 影响 |
|---|---|---|
| 点击测试、抓取前即写入浏览器配置 | `web/overrides.js` 的 `saveSetup` | 输入错误覆盖原配置，测试失败仍保存 |
| 只接受 `.workers.dev` 地址 | `web/overrides.js` 的 `wkRun` | 自定义域名无法通过检查 |
| localStorage 写入错误被忽略 | `web/overrides.js` 的 `HUB_STORE` | 存储被禁用或空间不足时，页面显示成功，但重开后丢失 |
| 作业、课件、公告请求失败直接变成空数组 | `web/overrides.js` 的 `fetchAll` | 看板缺少数据却显示成功，作业请求失败还可能触发错误的移除提醒 |
| 无请求超时及统一任务互斥 | 网页测试、抓取、订阅 | 长时间等待；重复点击可能并发写入快照 |
| 页面不知道 Worker 是否绑定 KV | `worker.js` 根路由、设置界面 | 用户填完提醒配置才发现不能启用 |
| 本地服务目录固定，脚本依配置输出 | `serve_board.py`、引擎 `update_site` | 自定义仓库路径或只在本地使用时，刷新结果可能读错位置 |
| 示例默认允许云端 push，且带占位路径 | `config/canvas_config.example.json` | 初学者不容易区分可选云端备份与必填设置 |
| 隐私说明未区分代理与订阅 | README、网页版指南 | 无状态代理不存令牌；启用订阅后令牌实际上会写入自己的 KV |

## 路线选择

| 路线 | 配置方式 | 适用人群 | 迁移与代价 | 建议 |
|---|---|---|---|---|
| A：现有架构优化 | 保留 GitHub Pages + 自有 Worker；保留本地 JSON；在原设置里加强检查 | 现有用户、手机用户 | 无需迁移浏览器字段；新 Worker 能力检测对旧版兼容 | 本轮推荐 |
| B：网页与代理一起部署到 Worker | 同一地址提供页面与 API，只配置 Canvas 令牌 | 愿意重新部署的网页用户 | 新部署流程和静态资源配置；地址变化后需要重新配置及迁移数据；现有 Worker 用户不能只替换 JS 完成迁移 | 后续主版本可考虑 |
| C：本地引导配置 | 增加标准库命令行向导及校验命令，生成本地 JSON | Windows 计划任务、AI agent 用户 | 增加配置管理代码与文档；仍需要 Python，不直接改善手机体验 | 本地用户优先时可选 |

三条路线均无需增加第三方依赖。B 的托管额度和平台配置应在实施前核对官方文档；本报告未承诺任何外部平台费用或部署耗时。

## 路线 A 的拟实施范围

1. 保留现有配置字段和凭证保存位置；统一校验 HTTPS 地址、令牌、到期日，接受 Worker 自定义域名。测试使用输入草稿，成功后再保存；抓取和订阅使用校验后的配置。
2. 增加操作进度、超时、互斥与存储失败提示。作业请求失败时中止本次抓取，保留旧快照；课件和公告部分失败明确提示，不伪装成完整成功。
3. Worker 根路由返回版本与 KV 能力；页面提前说明订阅是否可用，旧 Worker 仍可测试和抓取。
4. 修复本地服务目录与引擎输出不一致的问题，补足本地配置错误反馈；示例改为优先本地使用、云端备份明确选配，不改写用户现有配置。
5. 同步生成网页、更新使用文档与未发布更新记录；增加离线回归验证，覆盖非法输入、旧 Worker、失败保留快照、存储失败与并发操作。

## 保留与待决定事项

- 不迁移、清除或导出用户现有 Token 和课程数据，不改真实用户配置。
- 本轮不安装依赖，不触发真实 Canvas 抓取、订阅上传、微信推送或云端部署。
- 若选择 B，应先明确新入口地址和历史数据迁移方式，再调整部署配置。
- 若希望令牌改为“仅本次会话保存”，需额外决定每次打开重新输入的体验；本轮不默认改变长期保存行为。
- Git commit 和 push、部署发布均需单独确认。

## 验证与交付标准

| 范围 | 验证方式 | 限制 |
|---|---|---|
| 网页配置与抓取 | 使用 Node 内置工具模拟 Canvas、Worker 与浏览器存储；不使用真实凭证 | 模拟测试不能替代真实学校 API 和手机浏览器联调 |
| Worker 能力 | 直接调用 Worker 根路由，覆盖有 KV、无 KV | 不上传到 Cloudflare |
| 生成网页 | 执行现有 `web/build_web.py`，检查脚本语法和源码同步 | 环境速查中的旧 Python 路径均不存在；已找到 `D:\DevTools\anaconda3\envs_dirs\agent-sec38\python.exe`，版本 3.8.20，无需安装 |
| 本地引擎与服务 | 标准库离线配置与目录验证 | 无真实 Token，不宣称 Canvas 连通性通过 |

选择 A 后可作为 v2.2.0 候选迭代；只有实施并完成验证的内容才会写入更新记录。选择 B 或 C 后，实施范围相应调整。
