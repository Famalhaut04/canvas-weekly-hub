# 网页版使用指南（推荐 · 零安装）

> 打开一个网址 → 粘贴令牌 → 得到你自己的课程看板网站。
> 数据只存在你自己的浏览器里；手机、Mac、Windows 都能用。

**入口：https://famalhaut04.github.io/canvas-weekly-hub/web/**

---

## 为什么需要先部署一个"转发代理"？

城大的 Canvas 没有开放浏览器跨域访问（实测确认），所以网页无法直接调用 Canvas 接口。
解决办法是一个只属于你的转发代理（Cloudflare Worker）：

- **免费**：Cloudflare 免费额度足够个人使用
- **令牌不经过任何人**：代理部署在你自己的 Cloudflare 账号里，代码开源在本仓库，接受审查
- **只做一次**：之后一直可用

## 第一步：一键部署你自己的转发代理（约 2 分钟）

> ⚠️ 这一步只做一次。**零基础同学请先看 [Cloudflare 手把手图文教程](Cloudflare部署图文教程.md)**——
> 里面有序号步骤、英文按钮对照表、备用方案和常见问题，比本文更细。

1. 打开页面后，点「**一键部署（免费，约2分钟）↗**」链接
2. 登录你的 Cloudflare 账号（没有就免费注册一个）
3. 页面会自动填好配置，一路点 **Deploy / 创建**，直到显示部署成功
4. 复制页面给你的 **`.workers.dev` 地址**（形如 `https://xxx.your-name.workers.dev`）

## 第二步：粘贴令牌，生成你的网站

1. 浏览器登录 https://canvas.cityu.edu.hk → **账户 → 设置** → 页面底部 **+ 新访问令牌** → 生成并复制（只显示一次）
2. 回到网页版页面：
   - 「转发代理」：粘贴第一步的 `.workers.dev` 地址
   - 「访问令牌」：粘贴你的令牌
   - 「令牌到期日」：填生成页显示的日期（城大最长 90 天，剩 5 天会提醒）
3. 点「**🔌 测试连接**」→ 显示 ✅ 后点「**🚀 抓取并生成看板**」

几秒后即可看到你的看板：待办倒计时、提交状态、各课程新资料、历史归档。

## 第三步：开启提醒（三选多）

| 提醒方式 | 怎么开 | 效果 |
|---|---|---|
| 📅 手机日历 | 设置浮层点「📅 启用日历订阅 / 微信提醒」→ 复制订阅链接 → 手机日历 App 添加"订阅的日历"粘贴链接 | 订阅一次永久自动更新，截止前 2 小时系统提醒 |
| 💬 微信每日提醒 | 在 [sct.ftqq.com](https://sct.ftqq.com) 免费获取 SendKey 填入设置 → 点「启用日历订阅 / 微信提醒」 | 每天 18:30 微信推送未来 7 天待办与变化 |
| 🌐 离线单文件 | 点「⬇️ 下载我的学习网站」 | 得到「我的学习网站.html」，双击即开，可拷到手机 |

## 常见问题

- **点测试连接报"Failed to fetch"**：Worker 地址填错，或部署未完成，检查后重试
- **HTTP 401**：令牌错误或过期，重新生成
- **清除浏览器数据后要重新粘贴令牌**：看板数据存于浏览器 localStorage；建议定期点「⬇️ 下载我的学习网站」留存离线副本
- **为什么令牌要经过我的 Worker**：因为浏览器跨域限制必须中转；Worker 代码开源且部署在你自己的账号里，不存储、不转发给任何第三方

## 隐私

- 令牌只存在于你的浏览器与你自己部署的 Worker 中
- 课程数据只存在你的浏览器（可导出为离线文件）
- 本项目不设中心服务器，作者无法看到任何人的课程信息
