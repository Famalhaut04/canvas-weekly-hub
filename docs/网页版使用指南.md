# 网页版使用指南 · v2.2

## 第一次使用

1. 确认学校允许个人 API 使用；本项目手动 Token 模式不代表学校批准的应用，参见 [部署教程的前置条件](Cloudflare部署图文教程.md)。
2. 打开 [公共项目入口](https://famalhaut04.github.io/canvas-weekly-hub/web/)，选择“基础版”，一键创建或复制完整代码到自己的 Worker。
3. 从 Worker 概览 / Domains & Routes 打开自己的**正式网址**，看到“连接你的 Canvas”；不用填写代理地址，不使用编辑器预览网址。
4. 点击“登录城大 Canvas”完成学校 SSO，进入“账户 → 设置 → 新访问令牌”，填写用途和学校要求的到期日，按只显示一次处理，生成后立即复制。能否重看以学校界面为准。
5. 返回自己的助手粘贴 Token，点击“连接并生成看板”。显示课程看板才代表身份与主课程读取流程通过；空看板需再核对学校是否有活跃课程。

默认城大。其他学校在“其他学校 / 到期日 / 连接检查”填该校 HTTPS 域名（不含端口和路径）；令牌帮助链接随之指向该校设置页。

助手到期日是选填提醒，学校生成页可能必填；不延长学校令牌期限。不要依赖令牌能否再次显示，丢失或到期时在学校创建 / 再生后到助手设置替换，并重新连接。Token 本身并非只读，程序只调用查询接口。

“仅检查连接”只检查 Worker 和用户身份，成功会保存配置；不会验证课程读取。主按钮额外读取课程 / 作业；关键请求失败保留旧配置、看板与快照。部分课件 / 公告失败则保存可用结果并警告。浏览器存储故障只能尽力回滚，不能保证原子保存。

## 有 agent 使用经验

首次设置的“升级版”与“基础版”入口并列；升级版展开后提供 5 步本地路线、Python 命令、部署指南和“复制给 agent 的配置提示词”。已部署的个人 Worker 须更新本次完整代码才能显示新按钮。

提示词不读取你的配置或 Token；剪贴板不可用时展开文本框，手动复制。需要已有 Python 3.8+ 环境，配置 → --check-config → 抓取 → 离线 HTML 或 serve_board.py。详见 [本地部署指南](部署指南.md)。

## 日常操作

| 操作 | 功能 |
|---|---|
| 顶栏刷新 | 重新查询，关键失败保留旧看板 |
| 待办 / 课程动态 | 倒计时、提交状态、新资料、公告与变化 |
| 历史 / 搜索 | 切换记录，跨周搜索 |
| 日历按钮 | 下载 ICS；导入文件不会自动同步变化 |
| 设置 → 下载离线看板 | 导出时的 HTML 快照，不自动更新 |
| 设置 → 备份 / 导入 | JSON 迁移历史；排除配置凭证，课程内容不匿名 |
| 系统概述 | 数据流程与各部分功能 |

看板需手动刷新；关闭页面不会继续抓取。云端订阅 / 微信提醒暂停，不默认配置 KV、Cron 或 SendKey。

## 升级、迁移与排错

个人实例不会自动随作者发布升级。更新自己 Worker 的完整代码并确认生产部署成功。不同网址、设备、浏览器的历史不能自动同步：旧页面导出 JSON → 新页面导入（先备份当前历史，学校地址须一致）→ 重新输入 Token。更早旧版不一定有 JSON 导出入口，应先保留旧页面与数据。

旧订阅停用时先升级原 Worker，保留原 KV 绑定和原浏览器密钥，点击停用成功后再解绑；按钮只清理对应 cfg: / snap:，不清空 KV、不移除 Cron。密钥丢失时在自己的 Cloudflare 手动处理；旧 Token 要在学校撤销。

部署、Token、权限、超时、部分失败、存储及旧附件问题分别处理，见 [部署教程排错表](Cloudflare部署图文教程.md)。v2.2 Release 的 worker.js 与更新源码附件已同步本次修改；以前的下载和 GitHub 自带的历史标签源码包不会自动更新，不能仅凭版本号认定界面相同。

## 隐私

网页代码托管在自己的 Worker；个人配置与课程历史保存在当前浏览器。查询经自己的 Cloudflare 到学校，不经作者服务器、不上传作者仓库。星数请求仅访问 GitHub 公共 API，不携带 Canvas 信息。导出含课程隐私；清除浏览器不撤销学校 Token 或清理旧云端凭证。云端 agent 读取课程内容可能把内容发送给模型服务商，需单独理解此边界。详见 [系统概述](系统概述.md)。
