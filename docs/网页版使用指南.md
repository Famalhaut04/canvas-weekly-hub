# 网页版使用指南 · v2.2

## 第一次使用

1. 打开 [项目入口](https://famalhaut04.github.io/canvas-weekly-hub/web/)，创建自己的助手。
2. 打开部署成功后的自己的网址，看到“连接你的 Canvas”。
3. 点击“登录城大 Canvas”，在学校页面登录后，到“账户 → 设置 → 新访问令牌”生成并复制令牌；其他学校使用自己的 Canvas。
4. 粘贴到自己的网页，点击“连接并生成看板”。

默认城大；其他学校或到期日设置展开“其他学校 / 到期日 / 连接检查”。不需要填写 Worker 地址。创建方式见 [部署教程](Cloudflare部署图文教程.md)。

## 日常操作

| 操作 | 功能 |
|---|---|
| 顶栏刷新 | 查询课程，更新看板；失败时保留旧数据 |
| 待办 / 课程动态 | 查看倒计时、提交状态、新资料、公告与变化 |
| 历史 / 搜索 | 切换记录，跨周搜索 |
| 日历按钮 | 下载 ICS，导入自己的日历；导入文件不会自动同步变化 |
| 设置 → 下载离线看板 | 下载当前历史的 HTML，可离线查看 |
| 设置 → 备份 / 导入 | 通过 JSON 迁移历史，不迁移令牌 |
| 系统概述 | 了解数据流程与各部分功能 |

看板需手动刷新。v2.2 暂停云端订阅与微信提醒，没有 KV、SendKey 或定时器配置入口。

## 旧版迁移与停用订阅

新网址不能读取旧入口的浏览器历史：

1. 在旧入口的“离线查看 / 旧版数据迁移”中备份看板数据。
2. 打开新网址，导入下载的 JSON。学校地址须一致；导入会替换当前历史，建议先备份。
3. 重新填写自己的令牌。更新自己 Worker 的代码后才能使用一体化网页。

若曾启用云端订阅，先升级原 Worker；旧 Cron 在新版程序中不再查询或推送。原浏览器保留密钥时显示“停用旧版云端订阅”，点击可清理对应 KV 配置与快照；没有密钥时在自己的 Cloudflare 清理。还应移除旧 Cron，并在 Canvas 撤销不用的令牌。清除浏览器数据不能代替这些操作。

## 出错时处理

| 提示 | 操作 |
|---|---|
| 令牌无效 / 401 | 到 Canvas 重新生成令牌 |
| 403 | 检查权限或学校防护；持续限制云端访问时用本地 Python 路线 |
| 超过 20 秒 / 无法连接 | 检查网络和自己的网址，稍后重试 |
| 地址不合法 | 填 HTTPS 学校域名，不附带端口、路径、账号或参数 |
| 浏览器无法保存 | 允许本站存储或更换浏览器，不要把错误当成已保存 |
| 部分课件 / 公告未读取 | 查看警告并稍后刷新，空列表不一定表示没有内容 |

## 隐私

令牌和课程数据保存在当前浏览器，查询经自己的 Worker 到学校，不经过作者服务器。Cloudflare 会处理转发请求；请使用可信设备和自己部署的网址。星数请求只访问 GitHub 公共 API，不携带 Canvas 信息。备份、日历和离线 HTML 含课程隐私，应妥善保管。详见 [系统概述](系统概述.md)。
