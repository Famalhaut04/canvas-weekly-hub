## 用户反馈与已确认的问题

用户反馈 CS5489 作业已于 10 月 2 日提交，但看板显示未提交；进一步确认看板更新时间也是 10 月 2 日。**仅凭同一天无法判断抓取与提交的先后顺序，也无法确认外部提交平台是否已同步状态。**本轮未读取用户 Token、个人看板文件或真实学校提交响应，因此不能宣称已查明这份作业的根因。

已确认的代码缺陷：两端原来都用 `workflow_state` 是否属于 `submitted / graded / pending_review` 直接生成布尔值。提交对象缺失、状态未知也会得到 `False`，在界面中被显示成“未提交”。原实现也没有区分豁免、要求重交或时间与状态矛盾。

官方说明：作业列表 `include[]=submission` 返回请求用户的当前提交对象，某些响应可以没有该对象；不能据此推断本人未提交。`has_submitted_submissions` 表示至少一个学生提交，不能用来判断本人。见 [Canvas Assignments 官方资料](https://developerdocs.instructure.com/services/canvas/resources/assignments)。提交对象的时间、当前状态、豁免、重交和评分归属见 [Canvas Submissions 官方资料](https://developerdocs.instructure.com/services/canvas/resources/submissions)。

## 修正规则与证据

| 原描述 / 实际行为 | 可能误解 | 修正方案 | 证据 | 是否已实测 |
|---|---|---|---|---|
| 缺少 submission / workflow_state 被当成 False | API 未提供状态，被理解为未提交 | 使用 null / None；显示“状态待核验”，不计入未提交 | 共享夹具、两端回归、浏览器页面 | 模拟已验证；CS5489 未实测 |
| 有 submitted_at 但无 workflow_state | 忽略明确的提交时间 | 仅接受有效、含时区的时间为已提交依据 | 两端相同夹具 | 模拟已验证 |
| unsubmitted 与非空 submitted_at 矛盾 | 忽略历史提交，或反向误报已提交 | 显示待核验，不能断言当前完成 | 矛盾字段夹具 | 模拟已验证 |
| 外部工具 / 线下 / 不要求在线交付仍显示未提交 | 已完成交付被错误标红 | 没有正向提交证据时标待核验，保留作业链接供人工核对 | external_tool / on_paper / none 夹具 | 模拟已验证；学校平台同步未实测 |
| 豁免和要求重交被普通标签覆盖 | 用户以为需要提交，或误以为重交已完成 | 显示“已豁免” / “需重新提交”；不归入普通未提交 | excused / redo_request 夹具 | 模拟已验证 |
| 评分属于旧提交仍显示当前已评分 | 重交后的作业被当成已经评分 | grade_matches_current_submission=false 时不显示旧评分为当前评分 | 共享夹具 | 模拟已验证 |
| 看板更新时间与提交日期同一天 | 以为同一天的快照必然包含这次提交 | 查看完整时间并主动刷新；历史记录保持抓取时的状态 | 同日刷新回归、浏览器主动刷新模拟 | 模拟已验证；实际抓取顺序未知 |
| 刷新失败保留原记录 | 把原记录理解成刷新后的最新状态 | 原有失败保护与未更新提示保留，不修改历史数据冒充成功 | 既有关键请求失败回归、浏览器模拟 | 模拟已验证 |

本轮不新增提交、修改作业或写学校数据的接口；不改变 Worker 查询白名单。作业列表两端仍显式包含 `include[]=submission`。不要把 attempt、全班提交标记、迟交策略单独当作本人已提交的依据。

## 现在如何核对自己的作业

1. 保持本地看板服务运行，打开 `http://localhost:8137/`，按 `Ctrl+F5` 加载修改后的界面。
2. 点击顶部 **“刷新课程”**，等待抓取完成。浏览器页面刷新本身不会查询 Canvas；需要点击这个按钮。
3. 确认“最近更新”变为本次时间，并选最新日期记录。作业失败时会保留原记录，不能用旧日期状态判断当前提交。
4. 打开 CS5489 作业：若显示已提交，本次查询已取得正向证据；若显示待核验，在 Canvas / 提交平台核对；若最新记录仍明确显示未提交，需要核对该作业本人提交记录、外部平台或小组交付状态。不要重新生成 Token 当作通用解决办法。

本轮没有真实学校响应证据，不把“CS5489 已修复”作为验收结论。没有修改用户课程记录或手工把该作业改成已提交。版本保持 v2.2；未 commit、push、部署、发布或回复 Issue。
