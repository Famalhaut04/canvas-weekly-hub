## 两条最短操作流程

| 用户 | 步骤 | 成功标志 |
|---|---|---|
| 普通用户 | 确认学校许可 → 公共引导选网页部署 → 一键授权，或复制完整 worker.js 替换 Hello World 并 Deploy → 打开自己的正式网址 → 学校生成 Token 并立即复制 → 返回自己的助手填 Token → 连接并生成 | 显示自己的课程看板；文件 / 公告警告需检查，空看板需核对活跃课程 |
| agent 用户 | 确认学校许可 → 取得项目、已有 Python 3.8+ → 在本地复制示例、自行填学校地址与 Token，push_enabled=false → --check-config → 引擎抓取 → 双击离线 HTML，或启动 serve_board.py → 如需自动更新配置本机计划任务 | CONFIG_OK 只是格式通过；实际抓取成功并生成产物才算完成，电脑和网络须在线 |

入口按用户要求命名为“基础版”（网页路线）和“升级版”（本地 Python / agent 路线），旁边保留用途提示。按钮通过原生 button 支持 Enter / Space，aria-controls / aria-expanded 表明展开状态，选中路线会改变按钮样式。复制内容不拼接任何表单值；要求先阅读实际实现、不把 Token 发到聊天 / 日志 / 截图 / Git、安装前同意、禁止自动上传、以真实输出汇报，明确 Python 与云端模型边界。复制失败文本框只读、可聚焦全选，手机可滚动而无横向溢出。

## 隐私逐项核对

| 边界 | 实际实现与说明 |
|---|---|
| 各自 Worker | 一键复制到自己账号，手动也部署到自己账号；正式网页自动使用 location.origin |
| Cloudflare / 作者 | 网页查询经自己的 Worker 和学校；代码没有作者数据接收端，也不上传作者仓库；Cloudflare 仍处理请求，不保证托管商完全接触不到凭证 |
| 网页代码 / 个人数据 | 网页内嵌 Worker，个人 Token / 配置 / hubData / hubLastState 在浏览器 localStorage；浏览器存储不是加密保险箱 |
| KV / Cron / SendKey | wrangler 未配置；新请求不持久写凭证，scheduled 空操作；旧 KV 内容不自动清除，只可凭旧密钥清理对应条目 |
| 星数请求 | GitHub 公共 API，仅仓库星数；没有 Canvas 请求头或课程请求体 |
| 离线 / 日历 | 网页导出 HTML / ICS 是快照，未内嵌配置 Token；需要重新刷新、导出，不能当作持续订阅 |
| 历史迁移 | localStorage 按 origin / 浏览器 / 设备隔离；JSON 导入排除配置凭证但课程不匿名 |
| 清除 / 撤销 | 清除浏览器只清本地键，学校 Token 与旧云端资源另行处理 |
| 本地 Python | 直接学校请求、本地保存；GitHub 自动备份需显式开启，示例 false，程序没有自动确认仓库私有 |
| 云端 agent | AI 客户端把输入或读取的文件内容发给模型服务商属于另一条数据流；因此不作“全程只在电脑”的扩大承诺 |

没有真实凭证或个人课程测试、写入产物或提交。本轮截图中的 Token / 课程均为测试夹具，不是学生数据。
