# 零基础设置指南 · 一步一步拥有你的 Canvas 助手

> **全程只需要：一个能收邮件的邮箱 + 约 10 分钟 + 一根能点鼠标的手指。**
> 不用写代码、不用装软件、不用信用卡。
> 每一步都有「✅ 完成标志」——看到它再做下一步；卡住了就看该步的「❓卡住了」。

# 第 1 步：注册 Cloudflare（约 5 分钟）

Cloudflare 是一家国际云计算公司，我们借用它的免费服务安放你的「小助手」。

## 1.1 打开注册页

**你要做**：浏览器新开一个标签页，打开 👉 **https://dash.cloudflare.com/sign-up**

**你会看到**：一个只有两栏的页面——上面是 **Sign up（注册）**，下面是 Log in（登录）。

## 1.2 填邮箱和密码

**你要做**：
1. **Enter your email**：填你的邮箱（QQ 邮箱 / 163 / Gmail / 学校邮箱都可以）
2. **Create a password**：设一个密码（8 位以上，记在手机备忘录里）
3. 点蓝色大按钮 **Sign Up（注册）**

**❓卡住了**：
- 页面出现 **Verify you are human（人机验证）** → 按提示勾选方框即可（这是防机器人，不是故障）
- 点了按钮没反应 → 检查邮箱格式有没有打错

## 1.3 验证邮箱（关键，别跳过）

**你要做**：打开你的邮箱，找 Cloudflare 发来的邮件，点里面的 **Verify Email / 验证** 按钮。

**✅ 完成标志**：浏览器显示 "Email verified" 或自动进入 Cloudflare 控制台。

**❓卡住了**：
- 邮箱里没有？→ 先刷新邮箱，再看**垃圾箱**；等 5 分钟还没有，回注册页重试
- 用 QQ 邮箱收不到？→ 换 163 或 Gmail 重新注册一次

## 1.4 跳过新手引导（很多人在这里迷路！）

**你会看到**：进入控制台后，Cloudflare 可能弹出各种「欢迎」引导——问你 *What are you interested in?*（你对什么感兴趣）、让你选方案（Free 免费 / Pro 付费）、让你 **Add a domain**（添加域名）……

**你要做**：**全部跳过**——点 **Skip（跳过）** / 右上角的 **✕** / 选 **Free（免费）** 方案即可，我们都不需要。

**✅ 完成标志**：看到 Cloudflare 的**主控制台**——左边一条导航栏（Home、Analytics、Compute 之类），中间是概览面板。

# 第 2 步：创建你的「小助手」（约 3 分钟）

## 2.1 找到 Workers 入口

**你要做**：点左侧导航栏的 **Compute (Workers)**（有些界面版本叫 **Workers & Pages**，是同一个东西）。

> 🗺 新旧界面对照：
> - 新版导航：**Compute (Workers)** → **Workers & Pages**
> - 旧版导航：侧边栏直接就是 **Workers & Pages**

**✅ 完成标志**：页面中央出现你的 Worker 列表（现在是空的），右上角有蓝色按钮 **Create application**（或 **Create**）。

## 2.2 创建 Worker

**你要做**：
1. 点右上角 **Create application**（创建应用）
2. 在新页面点 **Create Worker**（创建 Worker）卡片
3. 出现 **Name your Worker**（给 Worker 起名）→ 填个简单的英文名，例如 `canvas`（只能小写英文、数字和连字符）
4. 点蓝色按钮 **Deploy**（部署）

**✅ 完成标志**：页面显示绿色的 **"Successfully published"**（发布成功），下方是示例代码（里面写着 Hello World）。

**❓卡住了**：
- 名字被占用（already taken）→ 换一个，比如 `canvas-lihua123`
- 没看到 Deploy 按钮 → 往下滚动页面

## 2.3 替换代码（最容易出错的一步，请仔细）

⚠️ **刚部署的 Worker 只是 Cloudflare 的示例程序（Hello World），还不是我们的小助手——必须替换成我们的代码。之前有同学漏了这一步，一直报错。**

**你要做**：
1. 在"Successfully published"页面点 **Edit code**（编辑代码）→ 进入在线代码编辑器
2. **回到课程助手的设置窗口**，点蓝色按钮 **「📋 一键复制小助手代码」**（约 240 行代码进入剪贴板）
   - 若浏览器询问"允许读取/写入剪贴板"→ 点**允许**
   - 复制失败也没关系：按**附录 A**手动复制
3. **回到代码编辑器**：点进代码区域 → **Ctrl + A**（全选，代码变蓝）→ **Ctrl + V**（粘贴，旧代码被覆盖）
4. 核对：粘贴后第一行是 `/** Canvas Weekly Hub · 轻量代理与提醒 Worker */`，整个文件约 240 行
5. 点编辑器右上角的蓝色 **Deploy**（部署）→ 弹出确认框再点一次 **Deploy**

**✅ 完成标志**：显示新版本号 + "Successfully published"；编辑器下方日志区没有红色报错。

**❓卡住了**：
- 粘贴后还是 Hello World → 没全选就粘贴了，重新 Ctrl+A 再 Ctrl+V
- Deploy 报红色错误 → 多半粘贴不完整，清空后重新复制粘贴一遍

## 2.4 复制你的小助手网址

**你要做**：
1. 点编辑器左上角的返回（← 你的 Worker 名），回到 Worker 概览页
2. 找到页面上方的网址，长这样：**`https://canvas.你的子域.workers.dev`**（子域名是注册时 Cloudflare 自动分配的）
3. **复制这个完整网址**（从 https 到结尾 dev）

**✅ 完成标志**：剪贴板里有了一个 `https://….workers.dev` 网址。

# 第 3 步：回到课程助手，填两格（约 1 分钟）

## 3.1 填小助手地址

**你要做**：回到课程助手网页的设置窗口，「小助手地址」一栏粘贴刚才的网址。

**✅ 完成标志**：粘贴后约 1 秒，输入框旁自动显示 **「✅ 小助手在线」**。
（网页会自动验证——没显示 ✅ 就按提示修正，别急着往下走。）

**❓卡住了**：
- 显示「地址应以 https:// 开头」→ 复制漏了前缀，重新复制
- 显示「连不上」→ 回 Cloudflare 确认 2.3 的 Deploy 成功；刚部署要等几秒生效
- 显示「能连上但不是本项目的代码」→ 2.3 的代码没替换成功，重做那一小节

## 3.2 生成并粘贴 Canvas 令牌

**你要做**：
1. 在设置窗口第❷步点 **「直达令牌生成页 ↗」**（会打开 Canvas；提示登录就用城大账号登录）
2. 在 Canvas 页面：**目的**随便填（如 `helper`）→ 点 **生成令牌** → **立刻复制**弹出的字符（⚠️ 只显示一次，关掉就看不到了）
3. 回到课程助手，「访问令牌」一栏粘贴
4. 「令牌到期日」填生成页显示的日期（格式 2026-12-30）——城大令牌最长 90 天，到期前 5 天页面会提醒你换
5. 点 **「🔌 测试连接」**

**✅ 完成标志**：显示 **「✅ 连接成功：你的名字」**。

**❓卡住了**：
- 找不到「生成令牌」按钮 → 确认在 Canvas 的 账户 → 设置 → 页面**最底部**
- 显示 HTTP 401 → 令牌复制不完整或已过期，回 Canvas 重新生成

## 3.3 生成你的看板 🎉

**你要做**：点 **「🚀 抓取并生成看板」**，等 5~15 秒。

**✅ 完成标志**：设置窗口自动关闭，你看到自己的课程看板——统计卡片（课程数/新任务/待办/新资料）、每门课的作业截止倒计时、未提交红标、新课件列表都在。

**先做这三件事**（看板顶部有提示条）：
1. 点顶部 **📅 截止日历** → 下载 `deadlines.ics` → 双击导入手机日历（截止前 2 小时自动提醒）
2. 在 **⚙️ 设置** 里点「⬇️ 下载我的学习网站」→ 得到离线网页，可发到手机随时看
3. 以后想更新数据：点顶部 **🔄** 按钮（约 10 秒刷新）

# 第 4 步（可选）：微信每天提醒你

设置窗口第❸步的「📅 启用日历订阅 / 微信提醒」可以做到**每天 18:30 微信推送**未来 7 天待办。需要两样东西：

1. **Server酱 SendKey**（免费）：手机微信扫码登录 https://sct.ftqq.com → 首页复制你的 **SendKey**
2. 填进设置窗口「微信 SendKey」一栏 → 点 **「📅 启用日历订阅 / 微信提醒」** → 出现日历订阅链接（加到手机日历 = 永久自动更新版提醒）

> ⚠️ 手动创建的 Worker 默认没绑定「存储」，启用订阅时若提示 KV 相关错误，按 **附录 B** 绑定一次（2 分钟）。

# 常见问题速查

| 症状 | 原因 | 解法 |
|---|---|---|
| Cloudflare 注册页打不开 | 网络波动 | 刷新重试，或换个浏览器 |
| 验证邮件收不到 | 邮箱拦截 | 翻垃圾箱；换 163/Gmail |
| 控制台里找不到 Workers | 新版导航改名 | 找 **Compute (Workers)** |
| 测试连接报 Failed to fetch | 小助手地址错 / 未部署完 | 看 3.1 的 ✅ 是否亮 |
| 报 HTTP 401 | Canvas 令牌问题 | 重新生成令牌（3.2） |
| 报 HTTP 403（含"防护拦截"字样） | 学校防护拦截了旧版代码 | 重做 2.3：粘贴最新代码并 Deploy |
| 点🔄没反应 | 正常，抓取要 5~15 秒 | 等按钮从 ⏳ 变回 🔄 |
| 清了浏览器数据要重贴令牌 | 数据存在浏览器里 | 重贴一次；建议常下载离线版 |

# 附录 A：一键复制失败时的手动复制

1. 打开 https://raw.githubusercontent.com/Famalhaut04/canvas-weekly-hub/main/worker.js
2. 页面显示一段代码 → **Ctrl + A** 全选 → **Ctrl + C** 复制
3. 回 Cloudflare 编辑器 **Ctrl + V** 粘贴

# 附录 B：给 Worker 绑定存储（KV）

1. Cloudflare 控制台左侧 → **Storage & Databases**（存储与数据库）→ **KV**
2. 点 **Create namespace**（创建命名空间）→ 名字填 `HUB_KV` → 创建
3. 回 **Compute (Workers)** → 点你的 Worker → 顶部 **Settings（设置）** 标签
4. 找到 **Bindings（绑定）** → **Add** → 选 **KV Namespace**
5. **Variable name（变量名）必须填 `HUB_KV`**（一个字母都不能错）→ KV namespace 选刚建的 → 保存
6. 回课程助手重新点「📅 启用日历订阅 / 微信提醒」

# 附录 C：以后怎么更新小助手代码？

我们会持续修复问题（比如之前的 403）。更新方法 = 重做一遍 **2.3**（复制最新代码 → Edit code → 全选粘贴 → Deploy），30 秒完成。
