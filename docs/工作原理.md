# 工作原理 · v2.2

用户模块说明见 [系统概述](系统概述.md)。

## 网页路径

网页和代理托管在同一个人 Worker。页面自动使用 `location.origin`；令牌通过 `X-Canvas-Token` 头发送，Worker 转为 Bearer 认证访问学校 Canvas。浏览器筛选近期内容、比较快照，将配置与历史写入 localStorage。

| Canvas 数据 | 用途 |
|---|---|
| 用户信息与课程 | 验证令牌、获取活跃课程与学期 |
| 作业及 submission | 截止提醒、提交状态、改期、新评分和移除检测 |
| 文件列表 | 展示新资料名称、类型、大小与上传时间 |
| 公告 | 展示近期标题与摘要 |

默认覆盖过去 7 天动态、未来 7 天任务，保留最多 52 份历史。作业失败、异常列表或分页截断中止抓取；课件和公告可部分失败并提示。相关配置、数据和快照一起保存，存储失败时尝试恢复旧值。单次浏览器请求超时为 20 秒。

## Worker 接口

| 接口 | 行为 |
|---|---|
| `/`、`/index.html` | 提供网页；旧版非 HTML 根路由探测仍返回 JSON |
| `/health` | 版本与能力，不返回凭证，subscriptions 始终为 false |
| `/overview` | 系统概述 |
| `/site-template/index.html` | 离线导出模板 |
| `/proxy/*` | 只允许用户信息、课程、指定课程的作业 / 文件 / 公告查询 |
| `/setup`、`/ics` | 返回 410，云端订阅暂停 |
| `/unsubscribe` | 仅用于持有旧密钥的用户清理对应 KV 配置与快照 |
| `scheduled()` | 空操作，避免旧 Cron 在升级后继续查询或推送 |

域名校验拒绝端口、路径、认证信息及 IP 字面量；代理不自动跟随重定向，不在 URL 携带令牌，课程响应使用 no-store。CORS 兼容旧页面；新网页连接限定同源及 GitHub 星数 API。网页使用脚本哈希 CSP、禁止框架嵌入、关闭 Referer；备份渲染转义文本并过滤危险链接。CSP 不等于端到端加密，Cloudflare 仍会处理请求。

`python web/build_web.py` 将源码、网页、说明与模板生成一个 `worker.js`，部署不用静态资源绑定或云端 Python 构建。维护时改 `worker/runtime.js`、`web/overrides.js`、模板或说明，然后重新生成。

## 本地路径

Python 3.8 标准库引擎读取 JSON，直接访问 Canvas；生成周报、data.json、ICS、离线 HTML，按配置下载课件。本地服务只在 loopback 提供公开文件与刷新接口，不公开配置。`--check-config` 仅检查格式。GitHub 推送默认关闭，启用时结果会上传到配置仓库。

## 隐私与兼容

无作者数据接收后端，无课程数据遥测，不默认开启 Worker 日志。配置凭证与课程历史在浏览器；导出不包含配置凭证，但包含课程信息。星数 API 不携带 Canvas 数据。

旧 Worker 可继续查询：页面先探测 `/health`，404 时回退根路由。已部署实例不会自动升级；旧订阅与 Cron 需按教程停用。新旧网址存储独立，备份与导入迁移历史、重新输入令牌。
