## 最终行为

- 部署网页与代理到同一个人的 Worker；默认城大，只填令牌，自动使用自己的站点地址。
- 普通查询不持久保存 Worker 凭证或课程数据；数据在浏览器处理并保存，不经过作者服务器。Cloudflare 会处理转发请求。
- 暂停 /setup 和 /ics，返回 410；subscriptions 为 false，scheduled 空操作。部署配置不创建 KV 或 Cron，不提供 SendKey / 微信启用入口。
- 只为旧订阅保留清理接口，凭原密钥移除对应 cfg: 与 snap:。不会自动清空旧 KV、删除旧资源或撤销学校令牌。
- 查询只开放课程相关 GET 接口，域名与令牌校验、不跟随认证重定向、敏感响应不缓存；不默认开启请求日志。
- 一体化网页使用脚本哈希 CSP、禁止嵌入与 Referer；链接过滤危险协议，课程文本转义。GitHub 星数请求不携带 Canvas 数据。
- 历史 JSON 备份 / 导入不迁移配置凭证；离线 HTML 和本地 ICS 保留。Python / agent 路线保留。

## 验证边界

真实浏览器通过本地 HTTP 桥访问完整生成的 Worker 页面与路由，上游 Canvas 由测试夹具替代。未部署到任何人的 Cloudflare 账号，未验证真实 Canvas 权限、防护及账号控制台流程；没有用户凭证，不把离线回归写成真实学校端到端成功。Safari / iOS 尚未验证。

浏览器测试曾被测试自身的全域 DNS 禁用规则阻止访问 loopback，已增加只允许本机的例外与禁用代理参数，重跑通过。这是测试隔离设置的修复，不是生产网络绕过。测试仅清理自身创建的 .tmp 私有配置目录，不删除用户文件。

云端订阅暂停并不等于 KV 或 Cron 不安全；这两项原来只服务于暂停的功能，因此本版不默认创建。需要云端功能时再独立设计与验证。

版本发布到 GitHub 与公共静态引导页；每个已部署的个人 Worker 仍需自己更新。
