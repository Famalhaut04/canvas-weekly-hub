# v2.2 · 部署一次，填令牌即用

- **配置更简单**：网页和代理统一部署到自己的 Cloudflare Worker；打开自己的网址，只填令牌即可生成看板。支持一键部署或仅邮箱复制代码，不需要 agent。
- **体验更顺手**：连接与生成合并，其他学校和到期日按需展开；增加历史备份 / 导入，修复手机设置窗口溢出。
- **失败有保护**：显示进度与错误原因；作业查询失败不覆盖旧快照，部分内容失败明确提示。
- **隐私更明确**：数据不经过作者服务器；代理只开放课程查询，敏感响应不缓存。备份不含配置凭证。
- **功能做减法**：暂停云端订阅和微信提醒，不需要 KV、Cron 或 SendKey；保留本地日历下载、离线看板及 Python / agent 入口。

**系统怎么工作**：浏览器经自己的 Worker 查询学校 Canvas，浏览器整理动态、比较快照，生成看板并保存到本机。Worker 提供网页与代理；Canvas 提供数据；浏览器负责处理和存储。

[系统概述与各部分功能](https://famalhaut04.github.io/canvas-weekly-hub/web/overview.html) · [开始使用](https://famalhaut04.github.io/canvas-weekly-hub/web/)

旧用户需更新自己的 Worker；迁移前先备份历史，导入后重新填写令牌。以前启用订阅的用户请按 [升级教程](https://github.com/Famalhaut04/canvas-weekly-hub/blob/main/docs/Cloudflare%E9%83%A8%E7%BD%B2%E5%9B%BE%E6%96%87%E6%95%99%E7%A8%8B.md) 停用旧订阅与定时器。
