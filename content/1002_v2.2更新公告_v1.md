# v2.2 · 基础版与升级版配置更新

版本号保持 **v2.2**。

- **基础版**：部署自己的 Worker，在自己的正式网址填写 Token，生成课程看板。
- **升级版**：使用已有 Python 3.8+ 环境，让 agent 协助本地配置；提供五步说明、安全提示词复制和复制失败回退。
- **配置更清楚**：新增城大 Canvas 登录入口，补全部署、令牌更换、历史迁移及排错；身份检查与课程读取分别提示。
- **隐私与保存**：查询可经自己的 Cloudflare，不经过作者服务器；网页 Token 和课程数据保存在当前浏览器。暂停云端订阅 / 微信推送，无需 KV、Cron、SendKey；云端 agent 读取课程内容可能进入模型服务商。

**系统怎么工作**：基础版由浏览器经自己的 Worker 查询学校 Canvas，浏览器整理动态、比较快照并保存看板；升级版由本机 Python 直接查询学校，生成周报、看板、日历和离线 HTML，agent 或计划任务负责运行。

**下载**：网页部署使用附件 **worker.js**；本地路线使用附件 **canvas-weekly-hub-v2.2-source.zip** 或 main。原 v2.2 标签不重写，GitHub 自动生成的 Source code (zip / tar.gz) 仍为历史源码，不含本次更新。

个人 Worker 不会自动升级，旧用户须重新部署完整代码；更新前先备份历史。请先确认学校允许个人 API 使用，手动 Token 模式不代表学校批准的应用；真实学校与 Cloudflare 账号部署仍待实测。
