# v2.2 · 课程读取与提交状态修复

2026-10-04 更新，**版本号仍为 v2.2**。

- **错误提示更准确**：区分课程权限 403、HTML 防护页、认证失败和网络问题；不再展示错误页脚本，也不再一律建议换 Token 或重试。
- **公告与课件读取修复**：公告改用正确接口；按 Canvas 分页信息读取，区分窗口已读完和结果不完整。
- **部分失败保留数据**：文件或公告失败仍可显示成功内容；保留旧内容时标注更新时间，不把读取失败显示成“没有资料”。
- **提交状态更可靠**：缺少提交信息显示“状态待核验”；豁免、要求重交分别标注。提交后需点击“刷新课程”，历史记录不会自动变化。
- **本地 HTTPS 兼容**：修复已复现的 Windows / Python 证书加载兼容问题，保留证书验证。

**为什么会有 403？** 学校返回 JSON `user not authorized`，说明该课程文件列表被 Canvas 拒绝访问；具体权限限制仍待核实。HTML 防护页则是另一类访问限制。403 不等于 Token 过期，本次更新不会绕过学校权限，也不保证无权读取的课件变为可读。公告 404、分页预算不足和本地证书错误是独立问题。

**系统如何工作**：基础版由浏览器经你自己的 Worker 查询学校，Token 和看板保存在当前浏览器；升级版由本机 Python 直接查询学校，生成周报、看板、日历与离线 HTML。查询不经过作者服务器，不上传作者仓库；云端 agent 读取内容时，数据可能进入模型服务商。刷新仍由用户主动选择，默认三天提醒只提示。

**如何更新**：先备份历史。网页用户下载附件 **worker.js**，到自己的 Worker 全选替换代码并 Deploy，再打开正式网址刷新课程；本地用户更新 main 或下载 **canvas-weekly-hub-v2.2-source.zip**，重新运行引擎。个人 Worker 不会自动升级。

原 v2.2 标签保留；GitHub 自动生成的 Source code (zip / tar.gz) 仍是历史源码，请使用更新附件或 main。云端订阅与微信推送继续暂停，不需要 KV、Cron 或 SendKey。

验证：105 项自动检查、20 项 Edge 浏览器模拟通过；真实 CS5489 提交状态、CS5187 课件及学校具体 403 权限原因仍未实测，本轮不宣称解决 Issue #4。
